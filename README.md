# AI 協作開發與研究

> 和 AI 一起寫程式、做研究，並且學會不盲目相信它。

AI 幾秒鐘就能寫程式、整理文獻、寫出一篇論文，但它也會編造內容、謊報完成、為了通過檢查而改寫數字。這門課從裝好工具開始，一步步練習：**讓 AI 做事 → 檢查它做的事 → 把檢查變成流程。**
