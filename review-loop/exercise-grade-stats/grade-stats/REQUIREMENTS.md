# 程式需求：CSV 成績統計

建立一個用 **uv** 管理的 Python 專案，執行方式：

```text
uv run grades.py grades.csv
```

輸入檔 `grades.csv` 的欄位為：`學號,姓名,國文,英文,數學`。

## 輸出

1. **各科統計**：有效人數、平均、最高、最低、**母體標準差**。平均與母體標準差顯示到小數點後 2 位；最高與最低顯示實際數值。
2. **不及格名單**：分數 **低於 60** 的學生、科目與分數（59.5 算不及格，不要四捨五入）。
3. **缺考名單**：成績欄位為空白或「缺考」者。缺考不列入統計。
4. **資料問題**：無法辨識的成績（非數字、小於 0、大於 100）要列出 **CSV 行號、學號、科目、原始內容**，且不列入統計；程式不能因此中止。
5. **重複學號**：同一個學號出現多次時，只採用第一筆，並列出被略過的行號。

> `grades.csv` 是從 Excel 匯出的真實格式資料，裡面有一些「髒資料」。**不要修改它**，程式要能直接處理。

## 限制

- 遵守 AGENTS.md 的規則：專案以 `uv init --bare` 建立，用 uv 管理，不准 `pip install`。
- 只用 Python 標準函式庫就能完成；若要使用第三方套件，須在判斷紀錄中說明理由。
